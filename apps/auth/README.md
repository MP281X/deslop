# Auth

Put `GITHUB_CLIENT_SECRET` in `~/.deslop/auth.env` for hosted GitHub sign-in.

On a Mac, set `EXPO_PUBLIC_APP_URL` to Auth’s HTTPS origin (defaults to `https://auth.mp281x.xyz`), run `vp run iphone:prepare`, install the generated iOS project's pods and build its Release scheme. Use that same native project and origin for `vp run build:iphone`.
