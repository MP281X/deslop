# Signal

A persistent factory simulation where AI teams build, explore and meet; you watch.

```bash
npm install --global @deslop/signal
signal service install --url https://signal.mp281x.xyz --auth https://auth.mp281x.xyz --run paused
```

- **Flags**: `--run running|paused`, `--context-tokens`, `--local-decisions`.
- **Secret**: `OPENROUTER_API_KEY` in `~/.deslop/signal.env`; without it no model runs.

Common flags and service commands: [Deslop app runtime](https://github.com/MP281X/deslop/blob/main/packages/runtime/README.md).
