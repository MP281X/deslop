# Deploy intent

- **Excluded.** A Monitor page, Memory|CPU tabs, the metric in the URL, per-core, network or disk I/O charts, a chart band for jobs.
- **One machine.** Show only the Linux machine Deploy runs on: no machine switcher, no link to another machine's Deploy, no macOS inventory.
- **Expose.** Ask only who can reach the port: Tailnet or Public.
- **Processes.** Hide process IDs, nameless listeners and routine system services. Leave process environments unread.
- **Controls.** Restart, Logs and Stop act only on owned user app services.
- **History.** Use one rolling hour for rows, the chart and processes. Draw restart lines at recorded starts, not when Restart is pressed. Show an authorised empty history as empty, not loading.
