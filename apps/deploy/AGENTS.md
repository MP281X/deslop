# Deploy intent

- One fleet with every worker in the machine filter. Blue identifies dev, purple desktop, consistently in device icons and measurements; availability uses dots, not online/offline text or a warning paragraph. Do not repeat the selected machine name or page title below navigation.
- Apps and monitoring have separate pages. Apps puts exposure first, with app-centric rows: type icon, name, endpoint pills and status dot. No raw peer list, protocol labels, image tags or detached details panel.
- Exposure controls keep their height when switching Tailnet/Public; Tailnet has no hostname input, and Public's hostname shares the input row. Picker names stay on one line with ellipsis, including Public's narrower picker. Shorten long unique identifier fragments, not meaningful names. Already exposed backends are absent. Use the shared Auth control and badge vocabulary.
- A sleeping worker must not delay local monitoring or the page shell. Show cached history immediately, then refresh workers with bounded deadlines and explicit offline states.
- Monitor has no Details disclosure. CPU history and cores stay separate; memory/cache/swap share proportional capacity tracks. Show total capacity once, absolute usage and percentages consistently; leave unused capacity as the unfilled track, not a free-space segment/legend. Storage has no partitions. Every range uses 60 equal-width time slots with clock-aligned axes; unrecorded slots stay blank.
- Retain minute samples for one hour, quarter-hour samples for one day and hourly samples for one week. Browser, worker and MCP responses return at most 60 points regardless of range, with current details once, not cores and mounts at every point.
- Context controls stay above scrolling results. A full app row exposes its condensed descendants at once: collapse wrapper chains, group identical leaves, indent at most twice. CPU and resident memory share fixed columns; chevrons sit at the far right. PID/PPID remain internal; never read command lines or environment. Count top-level apps; omit nameless listeners and ordinary system-service noise. Marks are transparent: canonical Deslop glyphs and software marks installed through SVGL's shadcn registry. Leave breathing room before the scrollbar.
- Consistent control heights, row columns and chart baselines on phone and desktop. Meaningful information is visible without expanding records.
- No CPU/Memory column headers: fixed number columns and unit-bearing readings suffice. Keep the count beside search. Center icon and dot boxes on the same row axis; error detail uses the same destructive color as its dot and failed actions.
