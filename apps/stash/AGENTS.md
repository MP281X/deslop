# Stash intent

- **Queue.** The share extension, clipboard and compose screen save to the same list.
- **Article.** Stash reads and tags each saved link once.
- **AI.** Organising notes uses the person's Anthropic key, not their catalogue balance. Transcribing audio uses Zen when usable captions are missing. Keep usable speech even if part of the transcription fails. Treat audio as silent only when transcription confirms there is no speech.
- **Production notes.** Stay untouched until loaded into SQL by hand.
