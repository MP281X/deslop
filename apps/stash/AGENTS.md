# Stash intent

- The list is a reading queue: each row opens its article, and a first run offers Paste Link; the share extension, the clipboard and the compose screen all save into the same list.
- An article is a reading view: title, cover, summary and the full body; Stash reads and tags each saved link once.

## Journeys

- Sign in, then share a link from Safari: the share extension saves it with the app's session and it joins the list.
- Open a note Stash could not read: it says why, keeps what was read and offers the retry.
- Delete a note by swipe, menu or from its detail: its row waits eight seconds with Undo, then the note leaves the server; Undo keeps it.
