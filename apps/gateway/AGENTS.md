# Gateway intent

- **AI.** Each person saves an OpenCode service-account key for catalogue and Go and an Anthropic API key for Claude. Gateway sends Claude Messages directly to Anthropic; callers never receive the key and Claude never spends Zen's balance. Every figure belongs to one payer, so the home list shows one row each for Zen balance and the Anthropic key beside the servers. Anthropic usage is estimated from response token counts; OpenCode calls whose responses name no payer are not recorded. `~` marks estimated or incomplete spend.
- **MCP.** Connection and key removal tools are only for explicit user-requested maintenance or credential revocation, not routine page actions.
- **Upstreams.** One scoped session per server serves discovery and calls. Effect's client handles its supported protocol revisions; the SDK is retained for OAuth and servers that negotiate a revision Effect cannot speak. While choosing, a 4xx other than 401/403 can mean an older server rejected the modern revision, so it takes the legacy path. Only a failure that cannot have committed is retried: a 404 session or 401 authorization rejection re-establishes the session; an ambiguous call failure never retries the action.
- **Callers.** Calls and discovery on one upstream session run concurrently. HTTPS subdomains of Gateway's parent domain need no OAuth connection and receive the caller's id in `x-deslop-user`; third-party servers receive only their own OAuth bearer, never that identity claim. Only session acquisition and invalidation share a lock.
- **Excluded.** Tabs, a detail pane, a charts card, an app breakdown, a summary line, an Add server button or dialog.
- **Paste.** The field under the bar is the page's one action: an `oc_sk_` OpenCode key or an `sk-ant-` Anthropic key opens the one credential dialog; an http(s) URL adds a server.
