# Gateway intent

- One page: a full-width server list with no detail pane. Each row identifies the server, its host, available tools and connection state; Connect or Reconnect appears when needed. Remove sits in the row's context menu. The same leading slot keeps its width.
- The bar holds Copy MCP URL beside Add server, so the one URL a harness needs is a click away. Its palette lists the servers that need the user, every server, and the bar's actions; choosing a server brings its row into view. Searching is how the page moves; there is no page filter.
- An agent on another machine gets its own token by running Auth's agent script and approving it on the phone; the token is made there, never here.
