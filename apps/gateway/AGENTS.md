# Gateway intent

- One page: a single column of servers, centered at reading width on a wide screen, with no detail pane. Each row is one line: mark, name, host or why it needs the user, its tool count from wider screens, its light, and Connect or Reconnect when one exists; a reported failure shows in full in red beneath the line. Remove sits in the row's context menu. The same leading slot keeps its width.
- The bar holds Copy MCP URL beside Add server, so the one URL a harness needs is a click away. Its palette lists the servers that need the user, every server, and the bar's actions; choosing a server brings its row into view. Searching is how the page moves; there is no page filter.
- An agent on another machine signs in with an agent token made on Auth's Agents page; the token is made there, never here.
