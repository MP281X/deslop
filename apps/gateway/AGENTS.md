# Gateway intent

- One page: a server list in a reading column centred on the page both ways, as Auth's sign-ins are, with no detail pane. Each row identifies the server, its host, available tools and connection state; Connect or Reconnect appears when needed. Remove sits in the row's context menu. The same leading slot keeps its width.
- The bar holds no actions. Its palette lists the servers that need the user, every server, Copy MCP URL and Add server; choosing a server brings its row into view. Searching is how the page moves; there is no page filter.
- An agent on another machine gets its own token by running Auth's agent script and approving it on the phone; the token is made there, never here.
