# Scope intent

- One page is one flat operations list, failures first then the busiest, with no app groups: each row leads with its app's mark, then the operation name, the side glyph, errors, runs and typical duration. The same operation name from two sides is two rows. An operation is a root span's name; HTTP operations use method and route or path, with unmatched requests grouped rather than one row per scanner path. Scope keeps each service's newest ordered release, but never deletes an unversioned or unordered service for it.
- The chosen operation lists its slowest traces with its newest failures among them. Rows show age, a short trace ID, failure status and duration. Hover names the failing span; selecting the trace opens that span's diagnostic, not a repeated message on the row. Only top-level traces are rows. New arrivals appear directly, without animating row height or rescanning every trace merely to animate it.
- Spans share their trace's time scale and are 48px rows whose dividers run pane edge to edge. A span's bar takes the hue of the app that ran it, and a failed span is destructive; a span that crosses into another app leads with that app's mark. The first failure starts picked. Only a span with additional information opens the inspector: its error, attributes and logs follow the spans as full-bleed rows, without repeating its row or attributes such as `code.function` that only repeat its name. Selection stores operation, trace and span identities in the URL, never copies of live records. Back keeps the selection and moves up one level. The trace pane has no header: its age and ID already sit on the selected row, and there is no copy button.
- GitHub Actions is the CI side: each repository is a section with GitHub's mark, each workflow an operation, a run's trace its jobs and steps; a failed run's status names the step that failed, whose details link to its log.
- On a phone every list runs edge to edge in 48px rows with every operation column, and the trace detail pushes full-screen. The bar keeps its leading slot's width on every pane and names the pane, so the title and the search control never move.
- The bar's palette opens with ⌘K or the search control and lists the navigation keys — J and K move the focused list's selection, Enter drills into it, Escape moves back one level — then the chosen operation's traces, every operation and the other Deslop tools; typing filters them. Searching is how the page moves; there are no filter chips.
- Scope's waterfall keeps its own time-scale geometry and composes `Trace` only where a tree is the data shape.
