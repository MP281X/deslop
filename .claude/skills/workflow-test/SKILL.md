# Checks and behavioral proof

Read testing for test judgment and evidence; this skill adds only the assigned check/pipeline procedure.

Run each assigned command or behavior step once. Checks and rule-fixture tests run sequentially. Mechanical fixes need the brief's authorization; never change another check's inputs. A pipeline watch uses environment's blocking recipe and triages failed jobs from their actual logs. Testing owns selector, failure-inventory and rerun judgment. Establish pre-existing failure on the default branch only when assigned; never stash/reset/switch the shared tree. Return criterion outcomes, commands/exits/execution counts, changed paths and blockers, not a coordinator's delivery narrative.
