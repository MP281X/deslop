# Decisions

What the agent configuration holds, what changed and why, and what failed. Read it before you change `.claude`, `.codex` or the shared skills: a rejected approach stays rejected unless new evidence beats its reason.

## Owners

| Owner                                                   | Holds                                                                                                                                           |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `.claude/agents/pair.md` and `.codex/instructions.md`   | The system prompts. Each starts with its own harness section; every section from "# The user's pair" on is identical in both                    |
| `.claude/skills/{software-factory,explore,environment}` | Personal skills, installed on every worker; Codex paths link to them                                                                            |
| `.claude/skills/retrospective`                          | Repository-only: thread analysis, evals and this record; never installed on workers                                                             |
| Engineering, design and testing in both native roots    | Generated copies; edit the [package sources](../../../../tools/coding-standards/skills/), then run `node tools/coding-standards/src/install.ts` |
| Native settings                                         | Harness capabilities and the built-in features each harness turns off, never a copy of a skill                                                  |
| Claude's deny list and `.codex/rules/deny.rules`        | Pushes to the default branch, merges and marking drafts ready. The prompts cover the forms that `deny.rules` lists as gaps                      |

- **Environment first.** When agents reach for a missing tool or hit a machine limit, fix the machine, then delete the rule that worked around it. Keep a ready command only for a constraint without a fix, such as Dual's VPN.
- **Less is the default.** A rule stays only when an agent fails without it. Repository code is the exception: coding standards and lint stay strict, while scratch code follows no style rule.
- **Provenance.** Public sources of the shared skills belong in the [coding-standards README](../../../../tools/coding-standards/README.md#skill-sources).

## Adopted

| Decision                                                                                                | Why                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One software-factory skill, with review, publishing and captures as its references                      | Reviews are steps of the factory; one skill loads every procedure. Replaced `workflow` and `review` on 10-11                                                                     |
| MVP and YAGNI in both prompts, engineering and the cleanup audit                                        | User feedback on 10-11: code overbuilt, cleanup not aggressive. Blind judge on three example builds, MVP fit before and after: 7 to 9, 8 to 9, 6 to 8                            |
| Cleanup audits judge against the user's quoted request, and the next iteration applies them             | Audits against the plan kept parts the plan had added. Stash production pass: Codex old 3, 2, 4 and new 7, 8, 8 of 12; Claude old 8, 5, 4 and new 9, 10, 6                       |
| Questions end the turn; a 15-minute `schedule_task` takes the recommendation                            | Question cards sat idle for hours while he slept. An in-turn `t3_thread_wait` shows the thread as working and sends no notification                                              |
| `AskUserQuestion` denied, and Codex `default_mode_request_user_input` off                               | Both block the thread; the user wants no question tool                                                                                                                           |
| English in ASD-STE100 Simplified Technical English, whatever the user's language                        | User request on 10-11; one standard replaced five separate style rules                                                                                                           |
| Compact text: omit what does not change an agent's action                                               | User request on 10-11. A compact rewrite lost 13 needed rules, so every rewrite gets a review against the previous text                                                          |
| "Layer" names only an Effect Layer; "brief" only a child's prompt                                       | Both words had two meanings in the configuration                                                                                                                                 |
| Direct children only; every brief opens with "You are a child agent: never delegate or launch threads." | No case justified a second level; finished children kept acting on pipeline events. Example children told to act as the primary delegated grandchildren                          |
| Interactive renders: variants on the same data, a state selector, realistic mock data                   | The user liked the state-machine prototype and wants to try designs before code                                                                                                  |
| Agents tune design values themselves                                                                    | The user stays out of the loop; DialKit and other user-operated tuning tools are out                                                                                             |
| Bottom-up stacks that reuse their pull requests and return to draft after a push                        | The user merges bottom up. Fake `gh` evals: new pull requests 3 to 0, closed 9 to 6; ready pull requests turned back to draft 0 to 3 of 3 runs                                   |
| T3 review guides tour the code; bodies hold behavior and evidence                                       | Code links in bodies duplicated the guide                                                                                                                                        |
| `ci.yaml` for branches and `deploy.yaml` for main                                                       | The user wanted separate development and production workflows. npm trusted publishing is bound to the `deploy.yaml` name                                                         |
| pnpm `minimumReleaseAgeExclude: ["@deslop/*"]` on every worker                                          | The one-day release delay made `vpx @deslop/stash@latest` run the previous release                                                                                               |
| The Mac only hosts the iOS Simulator: Vite+ and Xcode, no Homebrew, git tools or sign-ins               | The organization manages it through MDM; the user turns it on when needed                                                                                                        |
| No GPU setup on desktop                                                                                 | The user does not use the GPU; the driver needed a console key enrollment at every reinstall                                                                                     |
| Branch cleanup deletes only branches whose pull request merged                                          | The old rule deleted pushed branches, including the open pull requests of a stack, which are never checked out                                                                   |
| Codex for evals and judges; Claude runs for Claude-only sections and close shared results               | User preference: Claude runs are slower and costlier                                                                                                                             |
| The retrospective improves itself: it collects its own steers and turns them into standing passes       | User request on 10-11: each iteration needs fewer manual steers                                                                                                                  |
| Decisions live in this reference, not in `.claude/README.md`                                            | User request on 10-11: one record of what was done and why, read by configuration work                                                                                           |
| Compact engineering and testing prose; every code example kept                                          | Example builds, Codex, 2 runs each, blind judge out of 30: code 23.5 to 25, tool 19 to 19; root check and tests pass in all 8; mean minutes code 12.1 to 10.6, tool 29.3 to 24.9 |
| No fast mode or service tiers                                                                           | GPT speed improved; the user does not want them                                                                                                                                  |

## Rejected

| Approach                                                                    | Reason                                                                                                                                                                     |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installing instruction changes without an eval                              | Each change gets an eval of old against new; the user reviews by merging the draft pull request                                                                            |
| Importing Emil's whole skill collection                                     | Its variant picker, audit fan-out and style defaults conflict; keep the targeted craft                                                                                     |
| The whole Interface Craft library in the design skill                       | Stash design probe, Codex, blind judge: 3,900-word versions scored simplicity 3 to 6 against 6 to 8 for 2,500 words, with equal scores on 6 criteria; only its values stay |
| A changed-files tree in every final reply                                   | The user found it noise, even compacted; T3's panels show the files                                                                                                        |
| Caps on how long a foreground call runs                                     | The user found a fixed limit arbitrary; long work runs in the background so steers arrive                                                                                  |
| Coordination protocols between children                                     | A checker idled behind GO and PAUSE gates while source changed                                                                                                             |
| Implementation children, even with separate files                           | In one checkout they waited on gates and reformatted each other                                                                                                            |
| Ending the turn while children run                                          | Each child's completion started its own turn that reread the context; one thread got six such turns in 30 minutes on 10-06                                                 |
| Linear or other tracker connectors                                          | The user does not want them; Dual's Jira uses `acli`                                                                                                                       |
| Agent writes to Jira                                                        | The user picks, assigns and moves tickets himself                                                                                                                          |
| Harness rules that block `acli` writes, and a sign-in script                | A prompt rule is enough; the user types the token himself                                                                                                                  |
| Codex `model_context_window` override                                       | Primary calls carried a median of 264k tokens; the recommended window compacts sooner                                                                                      |
| FFmpeg `drawtext` title cards and caption strips in proof videos            | The user rejected the flat navy card; HyperFrames composes the recording in the app's own style                                                                            |
| Remotion or screenshot reenactments for proof videos                        | Remotion needs a company license; a rebuilt UI proves nothing about the real app                                                                                           |
| A machine-wide lock and resource rules                                      | The user rejects rules shaped by machine limits; nested lock names deadlocked a child                                                                                      |
| Tailscale SSH instead of keys                                               | The user chose one shared key pair; the Mac's Tailscale app cannot be an SSH server                                                                                        |
| Copying sign-ins or configuration from another machine                      | The user can reset any machine at any time; each worker sets itself up. T3 settings are the exception, copied without `eval*` instances                                    |
| Wake-on-LAN through the Mac                                                 | The Mac shares a network with `desktop` only when the user is home and can power it on by hand                                                                             |
| Package-level preset adoption in deslop                                     | Deslop's root config extends the preset for the whole repository; Dual bumps every package in a cleanup pull request                                                       |
| Updating Codex, Claude Code and T3 in maintenance                           | T3 updates all three itself                                                                                                                                                |
| Template checklists, video durations and a separate Proof section in bodies | The user reads a body as a changelog: each change with its own evidence                                                                                                    |
| One prompt file shared by both harnesses                                    | Each harness keeps different built-in rules, such as Claude's tool preference and Codex's channels                                                                         |
| A fix step that builds the Codex prompt from `pair.md`                      | The user found it overcomplicated; the agent keeps the shared sections identical by hand                                                                                   |
| A diff-classification command                                               | The user does not want another CLI; the cleanup audit covers it                                                                                                            |
| A lint rule against every native button, input, select and textarea         | Deslop's reference code uses unstyled native rows and editors; only a native control styled like a control is reported                                                     |
| References inside the shared skills                                         | Agents load references inconsistently; the design skill got shorter wording instead                                                                                        |
| Asking every decision in one batch                                          | The Dual Apps brainstorm sent 18 questions in 5 cards and got 9 "not sure" answers; one question per reply replaced it                                                     |
| Harness hooks that steer agent behavior                                     | The user wants prompt-level fixes; a hook that blocked sliced reads was rejected                                                                                           |
| Analysis scripts inside the retrospective skill                             | Scripts change with every analysis; the skill keeps the measures and inline commands                                                                                       |
| Quoting a status example such as "Now the edits." in the no-text rule       | Eval: 3 of 7 build runs wrote such a message with the example, 0 of 6 without it                                                                                           |
| Effect Atom rules that cover only new frontend data                         | Eval: 1 of 4 bug fixes adopted atoms; moving the changed hook or runner to an atom raised it to 4 of 4                                                                     |
| Trimming engineering examples that lint also checks                         | They make code right on the first write; lint fix loops are slow, so only one-line trivial pairs go                                                                        |
| A scheduled retrospective                                                   | `desktop` runs only during the day; the user starts the retrospective                                                                                                      |
| Dependent pull requests on main                                             | 123 and 124 built on each other and shared the lockfile; squash merges conflicted. Such pull requests stack, and `gh stack link` rebases them                              |
| Expressive-surface rules inside product UI                                  | Morning-briefing redesign eval: the 3 old runs ranked 1 to 3, the 3 new ones 4 to 6; creative work has its own mode                                                        |
| Banned-default lists as the whole creative mode                             | Six launch pages with them still shared one skeleton; a concept step and screenshot critique reached studio level                                                          |
| GPT-6 Luna as the research model                                            | It quoted 3 agent lines as user corrections in one digest; GPT-6.1 Sol, Opus 5.5 and Haiku 5.5 quoted none                                                                 |
| Merge webhooks and a dispatcher thread                                      | The user removed them; he sets up webhooks by hand                                                                                                                         |
| Eval runs as plain CLI processes with stubbed T3 tools                      | They put skills in the system prompt and never touched T3; runs are T3 children on one provider instance per variant                                                       |
| Scenario tables scored by a judge over two runs                             | They counted words the new rule added and hid guards that got worse; a replay probe needs the old prompt to fail first                                                     |
| Deny patterns that match one exact command form                             | `git -C <dir> push origin main` and trailing flags got through; Claude's patterns match anywhere in the command                                                            |
| Auto-loading configuration notes as `.claude/AGENTS.md`                     | Claude loaded 20 KB into every deslop thread and Codex never loaded it                                                                                                     |
| A prose trim of the design skill, 2,573 to 2,466 words                      | Example builds, Codex, 10-12: judge equal (design 28 to 29 of 40), but mean minutes 10.4 to 14.0 over 4 runs each, slower in 3 of 4 pairs; the guard blocked it            |
| Deleting checkpoint refs of settled threads                                 | T3's turn diffs and reverts read them; only the legacy `refs/t3/checkpoints` namespace has no reader                                                                       |
