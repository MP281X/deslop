# Code review

**Depth.** Trace contracts through real consumers, failures, concurrency and ownership against the merge base/criteria. Challenge the author's assumptions, not just syntax. Keep only introduced/exposed, reachable violations unhandled by surrounding code; decisive probes beat speculation.

**Return.** Give actionable findings by consequence, or Clean. A finding names its path:line, reachable input, actual/required outcome and smallest fix. State missing decisive proof; retain unaffected review coverage. No separate reading map, raw diary or mandatory report template.
